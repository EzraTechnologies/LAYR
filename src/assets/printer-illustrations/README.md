# Bundled printer illustrations

Original LAYR schematic artwork: enclosed, open-frame and compact printers.
These 480 × 360 PNGs contain no third-party logos or photographs. They are
embedded in the app so the touch chooser works without a file picker or network.

Selecting one uses the existing raster-image validation, bounded JPEG compression
and printer/Moonraker-scoped IndexedDB storage. This does not permit imported SVGs
or arbitrary image URLs.
